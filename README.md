# Ejercicios interactivos con JavaScript

Pequeña colección de ejercicios web de primero de Desarrollo de Aplicaciones Multiplataforma. Cada actividad se abre en el navegador y utiliza HTML, CSS y JavaScript sin dependencias externas.

## Actividades

- **Adivina el número:** intenta acertar un número aleatorio dentro de un límite elegido, con cuatro vidas.
- **Lista de tareas:** añade tareas a una lista durante la sesión.
- **Simulador de dados:** muestra diez lanzamientos aleatorios de un dado.
- **Tabla de multiplicar:** genera la tabla del número seleccionado.

La página principal enlaza las cuatro actividades.

## Tecnologías

- HTML5
- CSS3
- JavaScript (DOM y eventos)

## Cómo abrirlo

No necesita instalación ni servidor. Descarga o clona el repositorio y abre `index.html` en un navegador moderno. Desde la página inicial puedes elegir una actividad.

## Alcance actual

La lista de tareas no se guarda al cerrar o actualizar la página y, en esta versión, permite añadir tareas, pero no completarlas ni eliminarlas. Es un proyecto de aprendizaje inicial y se puede ampliar con esas funciones.
